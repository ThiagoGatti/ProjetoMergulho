# 🌊 Projeto Mergulho

Sistema desenvolvido em **Java com Spring Boot** para gerenciamento e controle de atividades relacionadas ao mergulho.

A aplicação permite realizar o **cadastro e gerenciamento de cilindros de mergulho**, controle de **estoque** e outras informações relacionadas aos equipamentos utilizados por mergulhadores e mergulhadoras.

## 🚀 Funcionalidades

* 👤 Cadastro e gerenciamento de mergulhadores
* 🧯 Cadastro e gerenciamento de cilindros
* 🔄 Controle de movimentação dos equipamentos
* 🔎 Consulta de informações cadastradas
* 🛠️ Gerenciamento de equipamentos relacionados ao mergulho

## 🛠️ Tecnologias

* **Java**
* **Spring Boot**
* **Spring Data JPA**
* **Hibernate**
* **Maven**
* **Banco de dados relacional**

## 📁 Estrutura do Projeto

O projeto utiliza uma arquitetura baseada em camadas, separando as responsabilidades da aplicação:

```text
src/
└── main/
    └── java/
        └── ...
            ├── controller/
            ├── service/
            ├── repository/
            ├── model/
            └── dto/
```

## ▶️ Como executar

### Pré-requisitos

* Java 21 ou superior
* Maven

## 📌 Objetivo

O projeto tem como objetivo facilitar o **controle de equipamentos e recursos utilizados em atividades de mergulho**, centralizando informações de cilindros, estoque e mergulhadores em uma aplicação web.
